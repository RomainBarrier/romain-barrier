## Ma démarche

- Structurer et rapprocher des données issues de publications publiques.
- Analyser les moteurs de croissance, de marge et de génération de trésorerie.
- Mettre en perspective les résultats, les risques et les hypothèses.
- Restituer les analyses dans des tableaux de bord interactifs accessibles dans le navigateur.

## Sources et limites

Ces projets personnels ne constituent ni des missions réalisées pour ces sociétés, ni des publications officielles de leur part. Les sources, périodes, calculs et limites sont précisés dans les études. Les hypothèses, scénarios et cas fictifs sont identifiés comme tels ; leurs résultats ne sont pas des performances professionnelles réalisées. Aucune recommandation d’investissement n’est formulée.

## Organisation et mises à jour

Le fichier `index.html` contient le portfolio et ses études intégrées. GitHub Pages publie la branche `main`, dossier racine. Pour ajouter une société, mettre à jour le portfolio et ce README ; le lien principal du CV reste identique tant que le compte et le dépôt gardent leur nom.
